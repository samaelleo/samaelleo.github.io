01.

درباره من

توسعه‌دهنده Full-Stack با بیش از ۱۰ سال تجربه حرفه‌ای در طراحی و توسعه وب‌اپلیکیشن‌های مقیاس‌پذیر، سیستم‌های توزیع‌شده و راه‌حل‌های ابری (Serverless). هسته تخصصم توسعه بک‌اند با Python/Django و پیاده‌سازی فرانت‌اند با JavaScript است.

در کنار توسعه نرم‌افزار به مدیریت زیرساخت سرور، شبکه و DevOps مسلطم و همیشه تلاش کرده‌ام پلی میان این دو دنیا باشم؛ همین باعث می‌شود یک محصول را از طراحی دیتابیس و API تا رابط کاربری، دیپلوی و نگهداری در محیط واقعی پیش ببرم.

به کارایی بالا، امنیت و رابط کاربری خلاقانه علاقه‌مندم و در سال‌های اخیر مدل‌های هوش مصنوعی را در سیستم‌هایی که طراحی کرده‌ام به کار گرفته‌ام.

class Developer: name = "Mohsen Karimi" role = "Full-Stack Developer" base = "Iran" stack = ["Python", "Django", "JavaScript", "PostgreSQL"] cloud = ["Cloudflare Workers", "D1", "KV"] ops = ["Linux", "Docker", "Nginx"] def motto(self): return "stable, fast & secure" # ✓
